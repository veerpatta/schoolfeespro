# SchoolFeesPro (VPPS)

SchoolFeesPro is a simple, secure fee management SaaS for Veer Patta Public School (VPPS), Amet, Rajasthan.

## Goals
- Make fee collection easy for non-technical staff
- Track dues by academic year
- Prevent fraud with append-only financial records and audit trails
- Keep hosting low/zero-cost using GitHub Pages + Firebase

## Tech Stack (v1)
- Frontend: React + Vite + TypeScript
- Hosting: GitHub Pages
- Auth: Firebase Authentication (Google Sign-In)
- Database: Firestore
- Backend: None in v1 (no Cloud Functions, no Storage)

## Roles (v1)
- DIRECTOR: full control (years, fee setup, students, promo approvals, audits)
- STAFF: collect payments (PAYMENT only), request promos
